Telegram Shop Bot
Магазин постеров в Telegram: каталог, карточки товаров, оформление покупки.

Стек
Python, aiogram, SQLite, Telegram Bot API

Возможности
— приветственный экран с баннером — каталог с ценами — карточка товара с кнопкой покупки — товары хранятся в базе, обновляются без правки кода

Запуск
pip install -r requirements.txt
Впиши токен своего бота от @BotFather в строку TOKEN в файле main.py
python main.py
